# Whisper: Audio to Text

## 1. What is Whisper?
Whisper is an AI speech-recognition model
developed by OpenAI.

It can:
- Convert speech into written text.
- Recognize many languages.
- Translate speech into English.

Example:
Hindi audio → Whisper → English text

## 2. Import Libraries
```python
import whisper
import time
```

- `whisper`: loads the AI model and
  processes audio.
- `time`: measures how long processing takes.

## 3. Load the Model
```python
model = whisper.load_model("base")
```

- Loads the Whisper `base` model.
- `model` stores the loaded AI model.
- `base` is a relatively small model.
- `large` is bigger and generally needs
  more memory and processing time.

Loading happens before our timer starts.

## 4. Start the Timer
```python
start = time.time()
```

- Records the current time in seconds.
- We use it as the starting point.
- Later, we subtract it from the ending time.

## 5. Transcribe the Audio
```python
result = model.transcribe(
    "/content/audio.mp3",
    task="translate",
    language="hi"
)
```

- `/content/audio.mp3`: audio file path.
- `model.transcribe()`: processes the audio.
- `language="hi"`: tells Whisper the
  original speech is Hindi.
- `task="translate"`: translates speech
  into English.
- `result`: dictionary containing the output.

Important:
- `task="transcribe"` produces text in
  the original language.
- `task="translate"` translates speech
  into English.

## 6. Display the Text
```python
print(result["text"])
```

- `result` is a dictionary.
- `"text"` is the key containing the text.
- `result["text"]` extracts the text.
- `print()` displays it on the screen.

## 7. Calculate Processing Time
```python
elapsed = time.time() - start
```

- `time.time()` gets the ending time.
- `start` contains the starting time.
- Subtraction gives the elapsed seconds.
- This measures transcription time,
  not model-loading time.

## 8. Convert Seconds into Minutes
```python
minutes = int(elapsed // 60)
seconds = elapsed % 60
```

- `//` gives whole minutes.
- `%` gives the remaining seconds.
- `int()` converts the minutes to an integer.

Example:
135 seconds // 60 = 2 minutes
135 seconds % 60 = 15 seconds

## 9. Display the Time
```python
print(
    f"Time taken: {minutes} minutes "
    f"and {seconds:.2f} seconds"
)
```

- `f` lets us insert variables into text.
- `{minutes}` displays whole minutes.
- `{seconds:.2f}` displays seconds to
  two decimal places.

Example output:
Time taken: 2 minutes and 15.00 seconds

## 10. Save Text into a File
```python
with open(
    "/content/translated_text.txt",
    "w",
    encoding="utf-8"
) as file:
    file.write(result["text"])
```

- `open()` opens or creates a text file.
- `"w"` means write mode.
- Existing content is overwritten.
- `encoding="utf-8"` supports many languages.
- `file.write()` writes the translated text.
- `with` automatically closes the file.

The file is stored in Colab's temporary
storage, not permanently in Google Drive.

## 11. Download the File
```python
from google.colab import files

files.download("/content/translated_text.txt")
```

- Imports Colab's file-download utility.
- Downloads the text file to your computer.

## 12. Dry Run: Example

Suppose transcription takes 135 seconds.

1. `start` records the starting time.
2. Whisper processes the audio.
3. `result["text"]` contains English text.
4. `elapsed` becomes 135 seconds.
5. `135 // 60` gives 2 minutes.
6. `135 % 60` gives 15 seconds.
7. The program prints the text and time.
8. The text is saved to a `.txt` file.
9. We download the file.

## 13. Important Notes

- Install Whisper once per fresh runtime
  when it is not already installed.
- Load the model before starting the timer.
- Save important outputs to Google Drive.
- A Colab runtime reset can delete temporary
  files and variables.
- Standard OpenAI Whisper does not
  automatically use a TPU just because
  a TPU runtime is selected.
- A CPU FP16 warning is not necessarily
  an error; Whisper can fall back to FP32.
